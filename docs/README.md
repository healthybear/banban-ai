## 📝 文档规范

### 文档命名
- 使用小写字母和连字符: `user-guide.md`
- 版本号格式: `PRD-v1.0.md`
- 日期格式: `2026-03-11-meeting-notes.md`

### 文档头部
所有文档应包含以下元数据：
```markdown
---
title: 文档标题
version: 1.0
author: 作者
created: 2026-03-11
updated: 2026-03-11
status: draft | review | approved | deprecated
reviewers: 评审人列表
tags: [标签1, 标签2]
---
```

### 文档状态
- `draft` - 草稿
- `review` - 评审中
- `approved` - 已批准
- `deprecated` - 已废弃
