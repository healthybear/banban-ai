# 衣食住行生活场景功能规划

## 产品定位

围绕**衣食住行**打造贴身 AI 管家，深入用户日常生活场景，提供真正有用的智能服务。

---

## 功能全景图

### 🧥 衣 - 穿搭助手

#### 核心功能
- **天气感知穿衣建议**
  - 结合天气 API（温度、降水、风力、体感温度）
  - 个人体感偏好学习（有人怕冷，有人怕热）
  - 场景适配（通勤、运动、约会、居家）

- **换季提醒**
  - 根据气温趋势判断换季时机
  - "该收夏装了" / "该拿出羽绒服了"
  - 衣物保养提醒（洗晒、收纳）

- **穿搭记录与搭配推荐**
  - 拍照记录每日穿搭
  - AI 分析风格（休闲、正式、运动、文艺）
  - 基于历史推荐搭配组合
  - 避免重复（"这套上周刚穿过"）

- **重要场合穿搭建议**
  - 面试、约会、运动、婚礼等场景
  - 结合天气 + 场合 + 个人风格

#### 实现阶段
- MVP: ❌ 不做
- v1.0: ✅ 天气穿衣建议 + 换季提醒
- v2.0: ✅ 穿搭记录 + AI 搭配推荐

---

### 🍜 食 - 美食管家

#### 核心功能
- **美食打分与记录** ⭐ MVP 核心
  - 快速打分（1-5 星 + 简短评价）
  - 拍照记录（菜品照片，自动识别菜名）
  - 自动记录位置和时间
  - 标签系统（川菜、火锅、甜品、性价比高等）
  - 支持多人聚餐记录（谁请客、AA、人均消费）

- **饮食时间提醒**
  - 学习用户饮食习惯（通常几点吃饭）
  - 超时提醒（"该吃午饭了，别饿着"）
  - 健康建议（"今天还没吃早餐"）

- **饮食健康分析**
  - 最近饮食趋势（太油腻、太辣、营养不均衡）
  - 热量估算（可选）
  - 饮食多样性评分

- **智能推荐** ⭐ MVP 核心
  - 不知道吃什么时推荐
  - 基于历史偏好（口味、价位、菜系）
  - 结合位置（附近餐厅）
  - 避免重复（最近吃过的不推荐）
  - 探店模式（推荐没去过的新店）

- **探店记录**
  - 去过哪些餐厅
  - 回访提醒（"这家店你上次评价很高，要不要再去？"）
  - 餐厅地图可视化

#### 实现阶段
- MVP: ✅ 美食打分 + 位置记录 + 简单推荐
- v1.0: ✅ 饮食提醒 + 健康分析 + 探店地图
- v2.0: ✅ 菜品识别 + 多人聚餐 + 高级推荐算法

---

### 🏠 住 - 生活空间管理

#### 核心功能
- **家务提醒**
  - 定期家务（打扫卫生、换床单、倒垃圾）
  - 季节性家务（换空调滤网、清洗窗帘）
  - 智能频率调整（根据实际完成情况）

- **物品位置记忆**
  - "我的充电器放哪了？"
  - 拍照 + 语音记录物品位置
  - 常用物品快速查询

- **居家环境监测**
  - 温湿度提醒（太干燥、太潮湿）
  - 空气质量提醒（开窗通风）
  - 结合智能家居设备（可选）

- **租房/买房记录**
  - 看房时记录优缺点
  - 拍照 + 语音备注
  - 多套房源对比

- **邻里信息**
  - 快递代收记录
  - 物业通知提醒
  - 邻里互助（可选社区功能）

#### 实现阶段
- MVP: ❌ 不做
- v1.0: ✅ 家务提醒 + 物品位置记忆
- v2.0: ✅ 环境监测 + 租房记录

---

### 🚗 行 - 出行助手

#### 核心功能
- **行动轨迹记录** ⭐ MVP 核心（配合美食打分）
  - 自动记录去过的地方
  - 停留时长统计
  - 轨迹地图可视化
  - 隐私保护（可选择性记录）

- **出行方案定制**
  - 路线规划（多种交通工具对比）
  - 时间预估（结合实时路况）
  - 成本计算（打车 vs 地铁 vs 骑行）
  - 最优方案推荐

- **出行风险预警**
  - 天气预警（暴雨、高温、大风）
  - 交通预警（拥堵、事故、施工）
  - 安全预警（陌生区域、夜间出行）

- **旅行规划与回忆**
  - 行程安排（景点、餐厅、酒店）
  - 旅行预算管理
  - 自动生成游记（照片 + 轨迹 + 文字）
  - 旅行回忆相册

- **通勤优化**
  - 学习通勤路线和时间
  - 避开拥堵时段建议
  - 通勤时间利用建议（听播客、学习）

#### 实现阶段
- MVP: ✅ 简单位置记录（配合美食打分）
- v1.0: ✅ 出行方案 + 风险预警 + 通勤优化
- v2.0: ✅ 旅行规划 + 轨迹可视化 + 游记生成

## MVP 阶段聚焦

### 为什么选这些功能？

MVP 聚焦**食 + 行（位置记录）**，原因：

1. **高频刚需**：每天都要吃饭，美食打分是真实痛点
2. **场景完整**：打分 + 位置 + 推荐形成闭环
3. **技术可行**：不需要复杂的 AI，基础功能即可验证
4. **用户粘性**：持续使用才能积累数据，推荐才准确
5. **差异化**：市面上缺少好用的个人美食记录工具

### MVP 核心功能清单

#### 1. 美食打分与记录
- [ ] 快速打分界面（1-5 星）
- [ ] 简短评价输入
- [ ] 拍照上传（可选）
- [ ] 自动记录时间和位置
- [ ] 餐厅名称输入/选择
- [ ] 标签系统（菜系、价位、场景）

#### 2. 位置记录
- [ ] 自动获取当前位置
- [ ] 地图选点（手动调整）
- [ ] 位置历史查看
- [ ] 隐私设置（是否记录位置）

#### 3. 智能推荐
- [ ] "不知道吃什么"入口
- [ ] 基于历史偏好推荐
- [ ] 附近餐厅筛选
- [ ] 避免重复逻辑
- [ ] 推荐理由说明

#### 4. 基础对话
- [ ] 自然语言打分（"刚吃的火锅不错，8分"）
- [ ] 查询历史（"我上次在哪吃的日料？"）
- [ ] 推荐对话（"推荐个附近的川菜"）

## 数据模型设计（初步）

### FoodRecord（美食记录）
```typescript
{
  id: string
  userId: string
  restaurantName: string
  location: {
    latitude: number
    longitude: number
    address: string
  }
  rating: number // 1-5
  comment: string
  photos: string[] // 照片URL
  tags: string[] // 标签
```

```typescript
{
  id: string
  name: string
  location: {
    latitude: number
    longitude: number
    address: string
  }
  cuisine: string[] // 菜系
  avgRating: number // 平均评分
  visitCount: number // 访问次数

```


## 技术实现要点

### 地图与位置服务
- 国内：高德地图 API / 腾讯地图 API
- 国外：Google Maps API
- 定位：浏览器 Geolocation API / 移动端原生定位

### 推荐算法（MVP 简化版）
```
推荐分数 = 历史评分权重 * 0.4
         + 距离权重 * 0.3
         + 新鲜度权重 * 0.2
         + 标签匹配权重 * 0.1

过滤条件：
- 最近 7 天去过的餐厅降权
- 距离 > 5km 的餐厅降权
- 用户偏好标签匹配加权
```

### 图片处理
- 压缩上传（移动端）
- CDN 存储（阿里云 OSS / 腾讯云 COS）
- 图片识别（可选，v1.0 再做）

## 用户体验设计要点

### 快速打分流程
```
用户刚吃完饭
  → 打开 App
  → 自动识别位置，推荐附近餐厅
  → 点击餐厅名
  → 滑动星级
  → 可选：拍照 + 评价
  → 保存（< 10 秒完成）
```

### 推荐对话流程
```
用户："不知道吃什么"
  → AI："你想吃什么菜系？"
  → 用户："随便，不要太辣"
  → AI："附近有 3 家你没去过的餐厅：
       1. XX 川菜（微辣，人均 80，评分 4.5）
       2. YY 粤菜（清淡，人均 100，评分 4.8）
       3. ZZ 日料（清淡，人均 150，评分 4.6）"
  → 用户选择或继续筛选
```
