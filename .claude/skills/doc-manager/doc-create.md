# 文档创建 Skill

创建大文档，自动分段生成，避免超出Claude输出限制。

## 使用方法

```
/doc-create [文档类型] [主题]
```

## 示例

```bash
# 创建PRD文档
/doc-create PRD LLM适配层

# 创建技术设计文档
/doc-create 设计文档 Agent编排系统

# 创建API文档
/doc-create API 聊天接口
```

## 实现流程

当用户调用此skill时，执行以下步骤：

### 第一步：生成大纲
```
1. 根据文档类型和主题生成详细大纲
2. 将大纲分成多个部分（每部分约500行）
3. 显示大纲供用户确认
```

### 第二步：逐段生成
```
1. 按大纲逐段生成内容
2. 每段生成后保存
3. 显示进度
4. 继续下一段
```

### 第三步：合并和完善
```
1. 合并所有段落
2. 检查一致性
3. 添加目录和索引
4. 保存最终文档
```

## 支持的文档类型

### PRD（产品需求文档）
使用模板: `docs/12-templates/PRD-template.md`

包含章节:
1. 概述
2. 用户分析
3. 功能需求
4. 非功能需求
5. 界面设计
6. 数据需求
7. 接口需求
8. 技术约束
9. 里程碑与排期
10. 风险与依赖

### 技术设计文档
包含章节:
1. 背景和目标
2. 系统架构
3. 模块设计
4. 接口设计
5. 数据库设计
6. 关键技术点
7. 性能考虑
8. 安全考虑
9. 测试策略
10. 部署方案

### API文档
包含章节:
1. API概述
2. 认证方式
3. 通用规范
4. 接口列表
5. 错误码
6. 示例代码
7. 变更日志
