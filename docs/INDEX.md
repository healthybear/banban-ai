## 💡 使用技巧

### 搜索文档
```bash
# 在docs目录下搜索关键词
grep -r "关键词" docs/

# 搜索特定类型的文档
find docs/ -name "*agent*.md"
```

### 查看文档结构
```bash
# 查看目录树
tree docs/ -L 2
```

### 生成文档索引
```bash
# 运行索引生成脚本
npm run docs:index
```
