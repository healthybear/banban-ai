# 端侧 AI 智能（On-Device Intelligence）

## 背景与定位

移动端存在两类 AI 需求，采用不同策略：

| 场景 | 策略 | 原因 |
|------|------|------|
| UI 判断、布局时机、简单分类 | 端侧 TFLite INT8 | 需要即时响应，< 10ms 延迟 |
| 复杂推理、多步骤 workflow、生成 | 云端 LLM（Genkit for Dart） | 需要强语言能力 |

端侧模型不替代云端，而是承担**高频、低延迟、无需生成能力**的分类与检测任务。

---

## 技术方案

- 模型格式：TFLite INT8 量化
- 模型大小目标：5–20MB（单个模型）
- Flutter 集成：`tflite_flutter` 包
- 推理延迟目标：< 10ms
- 离线可用：是，不依赖网络

## 可实现的功能优化点

### 1. 输入行为检测 → 动态布局调整

检测用户输入节奏和模式，实时调整界面布局。

| 检测信号 | 判断结果 | UI 响应 |
|----------|----------|---------|
| 短时间内连续发送多条消息 | 用户处于快速输入状态 | 折叠历史消息列表，扩大输入区域 |
| 输入内容超过 3 行 | 长文本输入 | 自动切换为全屏输入模式 |
| 输入停顿 > 30s | 用户思考中 | 显示快捷回复建议 |
| 连续删除重写 | 用户不确定意图 | 显示意图引导提示 |

### 2. 消息内容分类 → 智能渲染

对消息内容做轻量分类，选择最合适的渲染方式。

| 内容类型 | 检测特征 | 渲染优化 |
|----------|----------|----------|
| 代码片段 | 含缩进、关键字、符号 | 切换代码友好布局，显示复制按钮 |
| 列表/步骤 | 数字序号、换行结构 | 结构化卡片展示 |
| 情绪化表达 | 情感词汇分类 | 调整 AI 回复语气提示 |
| 问题类型 | 疑问句分类 | 预判回复长度，调整加载动画 |
| 文件/链接 | URL、文件名模式 | 提前展示预览占位符 |

### 3. 用户状态检测 → 主动 UI 适配

通过行为模式推断用户当前状态，主动优化界面。

| 用户状态 | 检测依据 | UI 响应 |
|----------|----------|---------|
| 专注阅读 | 长时间无操作 + 滚动行为 | 收起侧边栏，进入沉浸模式 |
| 快速浏览 | 快速滑动，停留时间短 | 折叠长消息，显示摘要 |
| 夜间使用 | 系统时间 + 亮度传感器 | 自动切换低对比度主题 |
| 单手操作 | 触摸区域集中在屏幕下半部 | 关键操作按钮下移 |

### 4. 会话意图分类 → 智能路由

在消息发送前做轻量意图预判，提前准备资源。

| 意图类型 | 检测方式 | 优化效果 |
|----------|----------|----------|
| 日程相关 | 时间词、日期词检测 | 预加载日历数据，减少 Agent 响应延迟 |
| 任务创建 | 动词 + 对象结构 | 预显示任务卡片骨架屏 |
| 闲聊 | 无明确意图特征 | 跳过 Agent 路由，直接走对话模型 |
| 文件操作 | 文件名、格式词 | 预请求文件权限 |

### 5. 打字过程实时分析 → 输入辅助

在用户打字过程中实时分析，提供即时辅助。

| 分析内容 | 触发时机 | 辅助行为 |
|----------|----------|----------|
| 语言检测 | 输入前 5 个字符 | 自动切换键盘语言建议 |
| 话题连续性 | 与上文语义相似度 | 显示"继续上个话题"提示 |
| 复杂度评估 | 句子结构分析 | 预判是否需要多步 Agent，提前显示"思考中"状态 |

## 实现优先级建议

按照对用户体验的影响和实现难度排序：

1. **P0 - 消息内容分类**（代码/列表/普通文本）：影响大，模型简单
2. **P1 - 输入行为检测**（快速输入/长文本）：高频触发，体验提升明显
3. **P2 - 会话意图分类**（日程/任务/闲聊）：减少感知延迟
4. **P3 - 用户状态检测**（专注/浏览/夜间）：锦上添花
5. **P4 - 打字实时分析**：实现复杂，谨慎评估收益

---

## 与云端 AI 的协作边界

```
用户输入
   ↓
[端侧 TFLite] 内容分类 + 意图预判（< 10ms）
   ↓
├── 简单意图（闲聊）→ 直接发送，UI 即时响应
└── 复杂意图（日程/任务）→ 预加载资源 + 发送云端 LLM
                                    ↓
                           [云端 Genkit + DeepSeek]
                           多步骤推理 + Tool Calling
```
