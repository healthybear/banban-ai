# 文档章节读取 Skill

只读取文档的特定章节，大幅节省token。

## 使用方法

```
/doc-section [文档] [章节名]
```

## 示例

```bash
# 读取产品愿景的"目标用户"章节
/doc-section vision 目标用户

# 读取需求规划的"MVP范围"章节
/doc-section requirements-planning MVP

# 读取技术选型的"后端技术栈"章节
/doc-section tech-stack-update 后端技术栈
```

## 实现

当用户调用此skill时，执行以下步骤：

1. 定位文档
2. 使用Grep搜索章节标题
3. 提取该章节的内容（到下一个同级标题为止）
4. 返回章节内容

## 输出格式

```
📄 产品愿景 > 目标用户

## 目标用户

### 主要用户群
1. **知识工作者** - 需要管理复杂日程和任务的专业人士
2. **开发者** - 需要编程助手和工作流自动化
3. **创业者/自由职业者** - 需要全方位的个人助理
4. **效率爱好者** - 追求生产力工具的极客

### 用户画像示例

**张明 - 产品经理**
- 30岁，互联网公司产品经理
- 需要管理多个项目的日程、会议、待办
- 希望助手能主动提醒重要事项
- 需要与Notion、飞书、Jira等工具集成

...

需要查看其他章节吗？
```

## 支持的章节匹配

- 精确匹配: `## 目标用户`
- 模糊匹配: `目标用户` (自动查找包含该关键词的章节)
- 多级标题: 支持 `#`, `##`, `###` 等

## 优势

- ✅ 大幅节省token（只读取需要的部分）
- ✅ 快速定位信息
- ✅ 适合大文档
